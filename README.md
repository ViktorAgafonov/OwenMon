# OwenMon - Система мониторинга весов

## Обзор
OwenMon - это система мониторинга весов с использованием протокола Modbus TCP через Ethernet. Система позволяет получать данные о весе в формате int16, отображать их в реальном времени, сохранять архивы и формировать отчеты.

## Изменения в версии 2.1
- Добавлен полный набор настроек адресов регистров переменных Modbus устройства
- Улучшен пользовательский интерфейс настройки регистров
- Исправлены ошибки в сохранении настроек регистров

## Изменения в версии 2.0

- Добавлена поддержка получения данных о весе в формате int16
- Реализовано чтение битов состояния из устройства
- Обновлен пользовательский интерфейс для отображения информации о TCP-соединении
- Добавлены настройки подключения TCP в конфигурационном меню

## Технические требования
- Node.js 14+
- Устройство с поддержкой Modbus TCP

## Установка
1. Клонировать репозиторий
2. Установить зависимости с помощью `npm install`
3. Настроить параметры подключения в файле `config/config.json` или через веб-интерфейс
4. Запустить приложение с помощью `npm start`

## Настройка Modbus TCP
Для работы с устройством по Modbus TCP необходимо указать следующие параметры в файле `config/config.json`:
```json
{
  "modbus": {
    "connectionType": "tcp",
    "host": "192.168.1.100", // IP-адрес устройства
    "port": 502, // TCP-порт Modbus (обычно 502)
    "slaveId": 1, // ID устройства Modbus
    "pollInterval": 1000, // Интервал опроса в миллисекундах
    "registers": {
      "weight": 0, // Регистр, содержащий значение веса в формате int16
      "dispatch": 1, // Регистр сигнала dispatch
      "dumpInputTank_1": 2, // Регистры состояния танков
      "dumpInputTank_2": 3,
      "dumpInputTank_3": 4,
      "outTank_1": 5,
      "outTank_2": 6,
      "outTank_3": 7
    }
  }
}
```

## Настройка адресов регистров

Система позволяет гибко настраивать адреса регистров для всех переменных Modbus устройства:

1. Через веб-интерфейс: перейдите на страницу **Настройки** → **Настройки подключения Modbus** → **Адреса регистров** и укажите адреса:
   - Регистр веса (формат int16)
   - Регистр сигнала dispatch
   - Регистры входных и выходных танков

2. Через файл конфигурации `config/config.json` в разделе `modbus.registers`

При изменении адресов регистров перезапуск приложения не требуется, изменения применяются автоматически.

## Формат данных
Система работает со следующими форматами данных:
- **weight** - исходное значение, считанное из регистра
- **weightInt16** - значение веса, преобразованное в формат int16 (диапазон от -32768 до 32767)

## Использование
1. Откройте браузер и перейдите по адресу `http://localhost:3000`
2. На главной странице отображается текущее значение веса в формате int16
3. В боковой панели показана информация о подключении Modbus TCP
4. Доступны архивы с часовыми данными и данными по сменам
5. Можно формировать отчеты в формате Excel
